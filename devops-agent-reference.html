Architecture

Three loops connect GitHub and the Agent Space

Configuration flows in, findings flow out as events, and approved plans come back as pull requests.

Gap

No fix pull requests

No documented branch or PR creation. A coding agent fills this step.

Loop 1 · Configuration

Skills and custom agents ship like code

CloudFormation only accepts inline asset files. Importing from GitHub is API-only, so a small sync tool calls it from CI and the service fetches the content itself.

Pinned

Every import uses one commit SHA, so the agent runs exactly what was reviewed.

Guarded

Apply refuses unless asset folders are clean and already on the default branch.

Safe deletes

Removal needs an explicit prune flag and a maximum-deletes budget.

Loop 2 · Diagnosis

From alarm to root cause and a mitigation plan

The on-call engineer asks for the plan; the agent re-checks live state before writing it.

Loop 3 · Remediation

The mitigation plan becomes a draft pull request

Mitigation Completed is the handoff. The coding agent never holds a GitHub write token; a separate job pushes its patch.

Idempotent

One branch per plan, fix/<task>-<execution>. Re-approving never creates a duplicate PR.

Scoped

Start with service repos whose infrastructure the Agent Space actually monitors.

Honest

If tests fail, the draft PR still opens and says so in its title and body.

Controls

Every fix request moves through two human gates

Blocked diffs stop before any push. Nothing reaches production without the normal pipeline.

Gate 1

Approval label, checked against an approver allowlist.

Gate 2

Draft PR only. The agent can never merge or deploy.

Diff checks

Refuse .github/**, CODEOWNERS and any IAM resource or policy change.

Token isolation

The push job holds the GitHub token, has no model access and runs no repo code.

If one person must hold both gates on a small team, record it as a segregation-of-duties exception with compensating controls.

Identities

One identity per job, each scoped to one thing

GitHub reaches AWS through OIDC trust scoped by repo, environment and default branch. The only stored secrets are two GitHub App keys.
